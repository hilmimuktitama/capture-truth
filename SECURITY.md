# Security and privacy

Capture Truth processes supplied exports locally and performs no Jira or Confluence fetch. Candidate derivation metadata is enumerable and versioned so privacy decisions cannot be lost by serialization. `portable-summary` includes only approved structured/metadata candidates whose derivation, source reference, redaction, and size checks pass. `internal-evidence-pack` includes valid unreviewed structured/metadata candidates. Raw and mixed candidates are excluded from portable output. Review attribution is caller-supplied and not authenticated; it does not prove identity or truth. Raw-local-only output may contain exact confidential prose and must stay local. Redaction is defense-in-depth, not a confidentiality guarantee.
