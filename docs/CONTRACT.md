# Capture contract

Version 0.5.1 captures exported records only. `createEvidencePack` returns `kind`, `schema_version`, `generated_at`, `sources`, `candidate_claims`, `diagnostics`, and `summary`. Candidate review states are `unreviewed`, `approved_for_portable`, and `rejected`; extraction always emits `unreviewed`. Reviewed states require nonempty `reviewed_by` and RFC3339 `reviewed_at`, but the package does not authenticate identity: attribution is declared by the caller. Portable profiles exclude raw-body, mixed, and rejected candidates and validate derivation, source matches, redaction, and size.

Sources preserve `id`, `type`, URL/path, observation and source-update timestamps, owner, revision, content hash, locator, caveats, raw inclusion, and metadata. Candidate claims contain only text, optional `suggested_kind`, keyword classification, `unreviewed` status, and exact source references.

Source references may also contain the full canonical `note`, `heading`, `tableRow`, and `line` fields. Pack validation and review accept these schema-valid annotations; derivation matching ignores them because they are not derivable from Capture Truth source records. The `portable-summary` projection intentionally narrows references to derivation-bound `source_id`, `locator`, `path`, URLs, timestamps, revision, and hash, so unbound location annotations may be omitted. The internal evidence-pack profile retains accepted annotations.

Diagnostics are capture-quality signals only. `error` blocks contract-quality use; `warning` requires attention; `info` records an intentional compatibility or privacy event. Diagnostics do not assess truth, publication, artifact quality, or health.

The profiles are `portable-summary` (`portable: true`, `local_only: false`), `internal-evidence-pack` (`portable: true`, `local_only: false`), and `raw-local-only` (`portable: false`, `local_only: true`). `raw-local-only` may contain exact raw material and can never validate as portable. `repo-safe-summary` is a deprecated alias for `portable-summary` with the same flags and emits a deprecation diagnostic. Output modes are `pack` (default durable review surface), `export`, and `both`. See `schemas/` and `npm run contracts:verify`.
