# MCP setup

Run `npx capture-truth-mcp` with an MCP client. The 0.5.1 server is read-only and exposes `capture.normalize`, `capture.evidence_pack`, `capture.export`, `capture.candidate_review`, and `capture.doctor`. Inputs are already-exported records; it never fetches external systems. `capture.evidence_pack` defaults to `outputMode: pack`; use `export` or `both` for a projection and provide `profile` whenever an export is requested. `capture.export` requires `pack` and `profile` and returns the same projection as `buildProfileExport`. With no `outputMode`, candidate review preserves its historical portable-summary export response. `outputMode: pack` returns the reviewed pack; `export` returns the export; and `both` returns exactly `{ reviewed_pack, export }`. These modes enable sequential reviews. Portable calls reject `raw-local-only`.
